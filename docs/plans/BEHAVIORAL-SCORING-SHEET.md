# 行为评分人审工作单（C1/C2 用）

数据源：`/tmp/omo-eval-ocg/<场景>/session.jsonl` + transcript.txt；
机器支持附录：`MODEL-EVAL-REPORT-OPENCODE-GO.md`。本工作单把 10 维度评分
所需的事实与证据位置预填，审阅者只需逐项判定，不必翻原始日志。
